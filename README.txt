READY FOR YOUR NEXT TECHNICAL INTERVIEW
From Java and Spring Boot to Cloud, System Design, and AI-Assisted Development
Hussam Elnaqeb — First Edition November 2026

29 chapters, 200 interview questions, 20 coding practice problems without solutions,
29 one-page chapter cheat sheets, and editable diagrams.
Most interview questions have short model answers. Coding discussion questions
and challenge problems deliberately have no answers.

guide.md is the full manuscript. body.md and front.md are editable source sections.
cheat_sheets.json and cheat_sheets.md contain chapter summaries.
questions.json holds the numbered interview bank.

The coding challenge solution file is intentionally excluded.
Algorithms.java contains the separate searching and sorting chapter examples.
Other Java files contain teaching examples for their corresponding chapters.
These existing Java examples were previously checked locally; framework, cloud,
and database snippets are illustrative and require their own environment.

examples/checkout.spec.ts is an illustrative Playwright test; it was syntax-checked,
not executed against a deployed app. Adapt fixtures, routes, selectors, and baseURL.
examples/mcp.example.json is illustrative; pin a tested server version for team use.
examples/SKILL.example.md is an example workflow, not an authorization grant.
